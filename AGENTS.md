# Разработка официального skill «Где бензин»

- Это отдельный публичный репозиторий. Не копировать сюда серверы, секреты и
  конфигурацию основного проекта.
- Python-клиент использует только стандартную библиотеку Python 3.10+.
- В ответах указывать единый источник «Где бензин» и использовать общую выдачу API.
- Марка топлива не подменяется автоматически. Проверять наличие именно выбранной
  марки; у наличия и цены разные часы актуальности.
- Каждая АЗС сохраняет ссылку на `gde-benzin.ru` с `#station=ID` и `utm_*`.
- Публичное отображение данных сохраняет обе обязательные ссылки: сайт и YouTube
  автора; условия хранятся в `skills/gde-benzin/references/api-terms.md`.
- Обычные тесты: `python3 -m unittest discover -s tests -v`.
- Живая проверка запускается отдельно: `python3 tests/live_smoke.py`; не добавлять
  массовый опрос API в CI.
- Изменения контракта проверять по реальному API и поведенческим тестам.
